Overview

A versatile plant for freshwater aquariums.

Java Moss is a hardy freshwater aquarium plant valued for its adaptability, natural appearance and usefulness in shrimp and fish aquariums.

It can be attached to wood, rocks and decorations, where it gradually spreads and creates dense cover.

Its fine structure provides grazing surfaces, shelter for shrimplets and a natural place for biofilm to develop.

Care

What it needs.

Lighting

Java Moss grows well under low to medium lighting. Strong lighting is not required and may encourage algae if nutrients are unbalanced.

Placement

Java Moss can be attached to driftwood, rocks, decorations or aquarium-safe mesh. Avoid burying large portions of the moss beneath the substrate.

Water Conditions

  • Temperature: 18–28°C
  • pH: 5.0–8.0
  • Stable freshwater conditions
  • Gentle to moderate water flow
  • CO₂ supplementation is optional

Maintenance

Trim excess growth when needed to maintain its shape and prevent the centre from becoming too dense. Gentle cleaning can also help remove trapped debris.

Propagation

Java Moss is easy to propagate. Healthy sections can simply be trimmed and attached elsewhere in the aquarium, where they can establish new growth.

Shrimp Benefits

Its dense structure creates excellent grazing surfaces and hiding places for shrimp. It is particularly useful for shrimplets, which can shelter among the moss while feeding on naturally developing biofilm.

Frequently asked questions

Common questions.

Does Java Moss need CO₂?

No. Added CO₂ can encourage faster and denser growth, but Java Moss can grow successfully without CO₂ supplementation.

Can Java Moss be planted in substrate?

It is generally better attached to hardscape rather than buried. Burying the moss can trap debris and may cause covered sections to deteriorate.

Why is my Java Moss turning brown?

Browning can be caused by trapped debris, poor water conditions, sudden environmental changes or older sections of the moss dying back.

Is Java Moss good for shrimp?

Yes. Java Moss provides cover, grazing surfaces and areas for biofilm to develop, making it especially useful in shrimp and breeding aquariums.

Does Java Moss need strong lighting?

No. Java Moss can grow under relatively low lighting. Moderate lighting may encourage denser growth, but very strong lighting is unnecessary.
